Security Practices

All customer data is encrypted in transit with TLS 1.3 and encrypted at rest with AES-256. Encryption keys are managed in a dedicated key management service and are never stored alongside the data they protect.

API keys rotate automatically every 90 days. Customers receive a warning email 14 days before a key expires and can rotate manually at any time from the developer settings page. A revoked key stops working within 60 seconds across all regions.

Employee access follows the principle of least privilege. Production access requires hardware security keys and is reviewed every quarter. Every administrative action is written to an immutable audit log that is retained for 400 days.

Vulnerability reports are welcome through the security mailbox. The security team acknowledges every report within 2 business days and publishes fixes for critical issues within 14 days. A yearly penetration test is performed by an independent firm and the summary is available to customers under a non-disclosure agreement.
